# DompetKu

Aplikasi Android pencatatan keuangan pribadi, dibuat dengan Kotlin dan Jetpack Compose.

## Menjalankan proyek

1. Buka folder ini melalui Android Studio.
2. Tunggu Gradle Sync dan instal SDK yang diminta.
3. Buat emulator melalui Device Manager atau sambungkan ponsel Android.
4. Tekan **Run**.
